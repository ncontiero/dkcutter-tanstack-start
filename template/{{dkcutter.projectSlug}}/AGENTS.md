## Project structure

- `src/routes/`: file-based routes. `src/routeTree.gen.ts` is generated by the router plugin (`{{ pm }} run generate-routes`): never edit it by hand.
- `src/router.tsx`: router setup (context, default error and not-found components).
{%- if dkcutter.authProvider == "clerk" or dkcutter.useSentry %}
- `src/start.ts`: global request and server function middleware. Keep `csrfMiddleware`: a custom `start.ts` disables Start's automatic CSRF protection for server functions.
{%- endif %}
{%- if dkcutter.useSentry and dkcutter.useCloudflare %}
- `src/worker.ts`: Cloudflare Worker entry (`main` in `wrangler.jsonc`). It initializes Sentry and hands requests to `src/server.ts`.
{%- endif %}
{%- if dkcutter.useParaglideJs or dkcutter.useSentry %}
- `src/server.ts`: server entry{% if dkcutter.useParaglideJs %} (Paraglide middleware{% if dkcutter.useSentry %}, Sentry tunnel{% endif %}){% elif dkcutter.useSentry %} (Sentry tunnel){% endif %}.
{%- endif %}
- `src/env.ts`: environment variables, validated with Zod when the app starts. Server-only variables go in `server`, browser ones in `client` with the `VITE_` prefix.
- `src/components/`: app components{% if dkcutter.useShadcn %}; shadcn/ui components live in `src/components/ui/`{% endif %}. The theme (light, dark, system) comes from `ThemeProvider` and `useTheme()`.
{%- if dkcutter.authProvider == "betterAuth" %}
- `src/lib/auth/`: Better Auth server (`index.ts`) and client (`client.ts`). `src/routes/api/auth/$.ts` serves its endpoints; the sign-in and sign-up pages use `src/components/auth/`.
{%- endif %}
{%- if dkcutter.usePrisma %}
- `prisma/schema.prisma`: database schema. The client is generated into `src/lib/generated/` and exported by `src/lib/prisma.ts`.
{%- elif dkcutter.useDrizzle %}
- `src/lib/db/`: Drizzle client (`index.ts`), schema (`schema.ts`) and seed (`seed.ts`). Migrations go in `drizzle/`.
{%- endif %}
{%- if dkcutter.useTanstackForm %}
- `src/hooks/form.ts`: `useAppForm`, with the reusable fields from `src/components/form.tsx`.
{%- endif %}
{%- if dkcutter.useParaglideJs %}
- `messages/`: translations, one file per locale. `src/paraglide/` is generated from them.
{%- endif %}
{%- if dkcutter.useTriggerDev %}
- `src/trigger/`: Trigger.dev tasks.
{%- endif %}

## Conventions

- Import from `src/` with the `@/` alias.
- Formatting and import order are enforced by ESLint (`@ncontiero/eslint-config`, with Prettier). Run `{{ pm }} run lint:fix` instead of formatting by hand.
- Write Tailwind classes directly in `className`, not in variables, so Tailwind IntelliSense and the class lint rules apply to them.
- Add new environment variables to `src/env.ts` and `.env.example`. Never commit `.env.local`.
{%- if dkcutter.useParaglideJs %}
- Put every user-facing text in all the `messages/*.json` files and render it with `m.key()` from `@/paraglide/messages`. Don't access messages dynamically (`m[key]`): it bundles every message. Links are localized by the router, so keep writing paths without the locale.
{%- endif %}
{%- if dkcutter.useReactHookForm %}
- Forms use `useForm` with `zodResolver` and a Zod schema.
{%- elif dkcutter.useTanstackForm %}
- Forms use `useAppForm` with a Zod schema in `validators`. Add reusable fields to `src/components/form.tsx` and register them in `src/hooks/form.ts`.
{%- endif %}
{%- if dkcutter.useShadcn %}
- Add shadcn/ui components with `{{ exec }} shadcn add <component>`, then run `{{ pm }} run lint:fix` on them.
{%- endif %}
{%- if dkcutter.usePrisma %}
- To change the database, edit `prisma/schema.prisma` and run `{{ pm }} run db:migrate`.
{%- elif dkcutter.useDrizzle %}
- To change the database, edit `src/lib/db/schema.ts` (camelCase keys; the columns are stored in snake_case through `casing`), then run `{{ pm }} run db:generate` and `{{ pm }} run db:migrate`.
{%- endif %}
{%- if dkcutter.authProvider == "betterAuth" and dkcutter.useDatabase %}
- Better Auth's tables are in the schema with `uuid` ids (`advanced.database.generateId: "uuid"`). When adding a Better Auth plugin, add its tables too and keep `generateId: "uuid"`.
{%- if dkcutter.usePrisma %} `{{ dlx }} auth@latest generate` adds them to `prisma/schema.prisma`, keeping the existing models. It writes their id default as `dbgenerated("pg_catalog.gen_random_uuid()")`: change it to `dbgenerated("gen_random_uuid()")`, like the other models. Postgres stores the default without the `pg_catalog.` prefix, so Prisma would otherwise always see a difference between the schema and the database.
{%- else %} `{{ dlx }} auth@latest generate --output <file>` can write them, but it replaces the whole target file: write to a new file and copy the new tables into `src/lib/db/schema.ts`.
{%- endif %}
{%- endif %}
{%- if dkcutter.useCommitlint %}
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/) (checked by commitlint).
{%- endif %}

## Library skills

TanStack Router, Start, Query and Form, among other libraries, ship [Agent Skills](https://agentskills.io) in their npm packages, which [TanStack Intent](https://tanstack.com/intent/latest) loads on demand. To enable them, run this once in an interactive terminal:

```bash
{{ dlx }} @tanstack/intent@latest install
```

It asks which packages may provide skills, saves the choice in `package.json` (`intent.skills`) and adds a managed `intent-skills` block to this file. After that, agents find skills with `intent list` and load one with `intent load <package>#<skill>`.
